🚀 Deploy to GitHub Pages
1
Create a new GitHub account (if you don't have one) at github.com and sign in.
2
Click the + icon → New repository. Name it aspire-morning-dashboard. Set it to Public. Click Create repository.
3
Click uploading an existing file on the repo page. Drag and drop aspire-morning-dashboard.html. Rename it to index.html before uploading.
4
Go to Settings → Pages (left sidebar). Under Source, select Deploy from a branch → branch: main → folder: / (root). Click Save.
5
Wait ~2 minutes. Your dashboard will be live at: https://YOUR-USERNAME.github.io/aspire-morning-dashboard/
6
To update daily: go to your repo → click index.html → click the pencil ✏️ edit icon. Or just re-upload. Your data stays in browser localStorage on each device you use.
7
Pro tip: Bookmark the live URL on your phone and desktop. Each morning, open the dashboard, click Upload Excel or Manual Entry, and you're done!
